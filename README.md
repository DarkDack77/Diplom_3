# Diplom_3 — Stellar Burgers Autotests

## Описание проекта
Автотесты для веб-приложения Stellar Burgers.

Проект содержит UI-тесты для проверки:
- регистрации пользователя;
- входа в аккаунт;
- переходов по разделам конструктора бургеров.

## Технологии
- Java 11
- Maven
- JUnit 4
- Selenium WebDriver
- WebDriverManager
- Allure

## Как запустить тесты

Запуск всех тестов:

```bash
mvn clean test
