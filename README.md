# Diplom_3 — UI-тесты Stellar Burgers

Часть дипломного проекта по программе «Инженер по тестированию: от новичка до автоматизатора» (Яндекс Практикум).

Автоматизированные UI-тесты для веб-интерфейса Stellar Burgers: проверка форм входа и регистрации.

## Что покрыто тестами

- Отображение формы входа и формы регистрации
- Переходы между формами (вход → регистрация → восстановление пароля и обратно)
- Валидация полей форм

## Технологии

- Java 11
- Selenium WebDriver
- Паттерн Page Object — страницы вынесены в отдельные классы (`RegisterPage` и др.), локаторы хранятся в полях класса
- Allure — отчётность по результатам тестирования
- Maven

## Как запустить

```
mvn clean test
mvn allure:serve
```

## Особенности реализации

- Взаимодействие с API (создание тестового пользователя через `UserApiHelper`) вынесено в отдельный пакет от UI-тестов и Page Object классов
- Код прошёл ревью наставника: локаторы перенесены в поля класса, структура пакетов приведена в порядок, подключена отчётность Allure
